# PrimerProyectoAndroid

Este es mi primera aplicación desarrollada con Android Studio usando Jetpack Compose.

## Descripción

Aplicación básica para Android creada como parte de mi aprendizaje en desarrollo móvil.

## Tecnologías

- **Lenguaje:** Kotlin
- **Framework de UI:** Jetpack Compose
- **IDE:** Android Studio
- **Sistema de compilación:** Gradle

## Requisitos

- Android Studio instalado
- SDK de Android configurado
- Dispositivo físico o emulador con Android 7.0 (API 24) o superior

## Cómo ejecutar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/carlomederos/PrimerProyectoAndroid.git
   ```

2. Abre el proyecto en Android Studio.

3. Sincroniza el proyecto con Gradle.

4. Ejecuta la aplicación en un emulador o dispositivo físico.
